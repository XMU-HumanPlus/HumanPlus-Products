# HumanPlus Products

Documentation and release downloads for HumanPlus products. This repository contains product manuals and integration guides; application and SDK binaries are distributed as [GitHub Releases](https://github.com/XMU-HumanPlus/HumanPlus-Products/releases).

| Product | Description | Documentation |
| --- | --- | --- |
| HumanPlusMoCapPicoSDK | Android AAR for connecting SmartWear garments on PICO, receiving timed IMU data, calibration, recording, and optional UDP streaming | [SDK guide](HumanPlusMoCapPicoSDK/HumanPlusMoCapPicoSDK.md) |

## Downloading a product

1. Open [Releases](https://github.com/XMU-HumanPlus/HumanPlus-Products/releases).
2. Select the release tagged for your product and version, such as `HumanPlusMoCapPicoSDK/v1.0.0`.
3. Download the binary package and the matching manual from that release's assets.

Release assets are versioned separately from the manuals on `main`. Check the manual attached to your release when integrating a specific version. This repository does not contain the private development source code.
