# HumanPlusMoCapUnity 使用手册

本手册适用于 `HumanPlusMoCapUnity-Setup-v0.1.0.exe`。程序是 Windows 64 位动捕预览与 VR 辅助客户端，包含 `SimpleMoCap` 和 `MoCapToVR` 两个场景。安装包不包含动捕数据发送端、SteamVR 或第三方 VR 驱动。

## 安装与启动

1. 下载本 Release 附带的安装包和本手册。双击安装包，按提示完成安装；安装需要 Windows 管理员权限。
2. 从开始菜单启动 `HumanPlusMoCapUnity`。程序默认进入 `SimpleMoCap`。窗口可调整大小，最小为 1280 × 720。
3. 启动兼容的动捕数据发送端。客户端默认连接本机 `127.0.0.1:8888`，因此发送端应在同一台电脑监听该地址和端口。当前安装包没有面向最终用户的服务器地址设置界面。
4. 动捕连接成功后，模型会随姿态数据运动。需要重新校准时，按界面中的校准按钮并按发送端要求保持 T-Pose。客户端会发送 `RECALIBRATE` 指令，校准结果由发送端返回。

如果发送端未运行，客户端会尝试重新连接；没有动捕输入时无法显示实时姿态。安装包只负责接收和展示数据，不会自动启动发送端。

## 场景与 VR 辅助

使用界面上的场景下拉框可切换：

- `SimpleMoCap`：基础动捕预览。
- `MoCapToVR`：动捕预览、VR 辅助，以及按实际环境配置的 VRChat OSC / SteamVR 追踪输出。切换场景会重新创建场景内对象与动捕连接。

启用 VR 辅助前，先启动 SteamVR，连接并正确追踪头显与左右两个手柄，然后在 `MoCapToVR` 中点击 `VR Assist` 按钮。按钮旁的状态文字会报告启用结果；再次点击可关闭。如果设备未准备好，模式不会启用。请先确认动捕输入正常，再启用辅助。

启用后，头显旋转用于修正模型头部旋转，不改变模型的整体平移或朝向。程序使用头显到手柄的相对位置，在模型头部坐标附近重建手部目标，并在手柄距头显不超过当前阈值时通过手肘 IK 修正手臂；距离过远则保留原动捕手臂结果。当前安装包默认**不**用手柄旋转覆盖手腕旋转。VR 辅助效果依赖追踪质量、设备姿态和动捕骨架匹配，不能保证手部与真实手柄完全重合。

## 数据与兼容性

动捕输入为 TCP 数据流，以 `$` 分隔帧。姿态帧格式为 `pose#pos`：`pose` 是 24 个关节的轴角向量，每关节 3 个以弧度表示的浮点数；`pos` 是根节点 `x,y,z` 位置。发送端使用 `CMD:CALIBRATION_DONE` 通知校准完成。数据发送端需遵守客户端预期的关节顺序和坐标约定；格式正确但顺序不匹配仍会导致姿态异常。

VR 辅助需要 Windows 上可运行的 SteamVR Runtime、有效的头显追踪以及左右两个手柄追踪。VRChat OSC 与 SteamVR 追踪输出是可选集成，可能还需要目标应用或相应驱动；它们不影响基础动捕预览。屏幕空间的普通 Canvas 在 VR 头显内可能不可见，请在电脑窗口中操作按钮。

## 故障排查

- 没有姿态：检查发送端是否监听 `127.0.0.1:8888`、端口是否被占用、发送格式是否正确。
- VR 辅助无法启用：确认 SteamVR 已启动，头显及两只手柄均已连接且正在追踪。
- 手臂修正未触发：将手柄移近头显；`MoCapToVR` 场景当前的头显到手柄距离阈值为 1.6 米。
- 头部或手臂偏移：先确认动捕校准和 SteamVR 追踪原点稳定，再关闭、重新启用 VR 辅助以重新捕获旋转偏移。

此版本作为预发布提供。Windows 构建与安装包生成已验证；动捕发送端、SteamVR 设备、VRChat 和第三方驱动的现场联调仍需在目标设备上完成。
