## 下载产品

1. 打开产品表格中对应的版本链接，或在 [Releases](https://github.com/XMU-HumanPlus/HumanPlus-Products/releases) 中选择所需版本，例如 `HumanPlusMoCapPicoSDK/v0.1.0`。
2. 下载该版本的二进制文件和同一 Release 附带的使用说明书。

`main` 分支中的说明书可能随新版本更新。接入特定版本时，请以该 Release 附带的说明书为准。本仓库不包含私有开发源码。
